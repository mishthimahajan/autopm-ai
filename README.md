# 🚀 AutoPM AI  
### AI-Powered Project Management Assistant

AutoPM AI is an intelligent project management platform designed to automate project planning, task organization, and workflow management using Artificial Intelligence.

The system helps teams and individuals manage projects efficiently by providing AI-driven assistance, task handling, progress tracking, and productivity optimization.

Developed as a hackathon project, AutoPM AI combines modern web technologies with AI capabilities to simplify project execution.

# ⚙ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/mishthimahajan/autopm-ai.git
```

Move into project directory:

```bash
cd autopm-ai
```

---

## Backend Setup

Go to backend:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

Run backend server:

```bash
npm start
```

---

## Frontend Setup

Open frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start frontend:

```bash
npm run dev
```

Application runs on:

```bash
http://localhost:5173
```

---

# 🔑 Environment Variables

Create `.env` file inside backend folder:

```env
PORT=5000

MONGO_URI=your_mongodb_connection

OPENAI_API_KEY=your_api_key

JWT_SECRET=your_secret_key
```
